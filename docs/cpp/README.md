## Choose Your Platform

Install the SmartSpectra C++ SDK for your development platform first, then build
your app or samples against the installed `SmartSpectra::SDK` CMake package.

| Platform | Install Guide | Notes |
| -------- | ------------- | ----- |
| Ubuntu 22.04 / Mint 21 | [Linux](linux.md) | Debian package for amd64 and arm64 |
| macOS Apple Silicon | [macOS](macos.md) | Homebrew package; signing required for full SDK startup |
| Windows 10 / 11 | [Windows](windows.md) | NuGet and zip distributions |

For Ubuntu 24.04 / Mint 22, Debian 12, RHEL 9, and Fedora 41, contact
[support@presagetech.com](mailto:support@presagetech.com) for current platform guidance.
